# 13 — خارطة طريق المشروع

تسجل هذه الخارطة المراحل والبوابات المعتمدة، ولا توسع صلاحية التنفيذ المحددة في بقية وثائق المشروع.

## المرحلة الحالية

**إعداد محتوى الصفحة الرئيسية العربية ومراجعته**

يوجد سجل المحتوى في [سجل المحتوى التجاري الأولي](content/INITIAL-BUSINESS-CONTENT.md). اعتمد المالك في 2026-09-08 بيانات الشركة والتواصل المعروضة، وتصنيف الخدمات التسع، وأسماء العملاء والمشاريع، وإذن عرض هذه الأسماء.

## الإجراء التالي المعتمد

إعداد مسودة الصفحة الرئيسية العربية من السجلات المعتمدة فقط. تستبعد الإحصائيات والشهادات والنتائج والوسائط غير المعتمدة، وتعرض على المالك قبل الترجمة أو ملء قاعدة البيانات أو تنفيذ التطبيق.

## أعمال مؤجلة

- تصميم وتنفيذ seed لقاعدة البيانات
- تعديل Prisma أو migrations
- تنفيذ الصفحات والداشبورد
- تنزيل أصول الموقع القديم
- تحويل المسارات والنشر
